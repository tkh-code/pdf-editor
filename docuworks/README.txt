DocuWorks → PDF 変換（PDF編集ソフトの付属ツール）
=================================================

DocuWorks 文書（.xdw）・バインダー（.xbd）を PDF にします。
DocuWorks が入っている Windows PC で動きます（Python などのインストールは不要）。

■ 準備（PCごとに最初の 1 回だけ）
  1. この ZIP を「すべて展開」する
  2. setup.bat をダブルクリック
     （「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」）
  3. これで準備完了です。次回からは Windows にログオンすると自動で待機します

■ 使い方
  ・PDF編集ソフト（https://tkh-code.github.io/pdf-editor/）に .xdw / .xbd をドロップ
    → その場で PDF にして開きます。設定は「変換」→「DocuWorks → PDF」
  ・デスクトップの「DocuWorks→PDF変換」にドロップ／右クリック「送る」でも、まとめて PDF にできます
    （PDF は元のファイルと同じフォルダ。同名があれば「名前 (2).pdf」）

■ 速さ・重さ
  ・複数ページを同時に変換するので、2,000 ページ近い構造計算書でも数分です
  ・白黒のページは 300dpi の白黒（1ページ数十KB）、色や塗りのある所だけカラーで重ねるので軽くなります

■ 注意
  ・ページを画像にするため、PDF の文字は選択・検索できません
  ・パスワード付きの文書は変換できません
  ・Edge / Chrome で初回に「ローカル ネットワーク上のデバイスへのアクセス」を聞かれたら「許可」してください
  ・アンインストール：スタートアップ・デスクトップ・送る にある「DocuWorks→PDF変換」関連のショートカットと
    %LOCALAPPDATA%\DocuWorksPDF フォルダを消す
