# PDF編集ソフト

Acrobat の有料機能（文字の追加・書き換え、ページの追加・並べ替え・削除など）を、
社内PCだけで動かせるようにした PDF 編集ツール。ネット接続不要・ファイルは外部に送信しない。

## 起動

- `start.bat` をダブルクリック → ブラウザ（Edge/Chrome）で画面が開く
- PDF を `start.bat` にドラッグ＆ドロップすると、そのPDFを開いた状態で起動
- 終了は黒いウィンドウを閉じる

必要なもの：Python 3 と PyMuPDF（`pip install pymupdf`）。このPCには導入済み。

## できること

| 分類 | 機能 |
|---|---|
| 文字 | 文字追加（游ゴシック／太字／游明朝／メイリオ／MSゴシック／Arial／Times、サイズ・色）、**既存の文字の書き換え**（文字修正ツール） |
| 書き込み | 白塗り（修正テープ）、マーカー、四角、楕円、線、矢印、手書き |
| 画像 | 画像・印鑑画像の配置（拡大縮小）、スタンプ（承認・確認済・日付・和暦 など／任意文字） |
| ページ | 追加（PDF・画像・空白ページ）、ドラッグで並べ替え、削除、回転、複製、複数PDFの結合 |
| 保存 | ページ番号付与、透かし文字、パスワード設定、圧縮、選択ページのみ保存 |
| 分割 | 選択ページの抽出、1ページずつ・Nページごと・範囲指定（例 `1-3, 4-6`）で分割 |

元に戻す（Ctrl+Z）・やり直し（Ctrl+Y）、Ctrl+ホイールで拡大縮小。

## 注意

- 文字修正はPDFに文字データがある場合のみ。スキャンPDFは「白塗り」＋「文字追加」で対応。
- 白塗りは見た目を隠すだけで、下の文字データは残る（コピーや検索で拾える）。
  文字そのものを消したい場合は「文字修正」で空にする。
- Arial／Times は英数字専用（日本語は表示されない）。
- 元のPDFは上書きしない。保存先とファイル名は保存時に指定する。

## ファイル

- `server.py` — ローカルサーバー（PyMuPDF でページ描画・PDF書き出し）
- `index.html` — 編集画面
- `start.bat` — 起動用
