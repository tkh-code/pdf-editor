# PDF編集ソフト

Acrobat の有料機能（文字の追加・書き換え、ページの追加・並べ替え・削除など）を、
ブラウザだけで使えるようにした PDF 編集ツールです。インストール不要・無料。

## 使い方

**https://tkh-code.github.io/pdf-editor/** を開くだけです（Edge か Chrome 推奨）。

1. PDF を画面にドラッグ＆ドロップするか「開く」を押す
2. 上のツールで文字を書き込んだり、左のサムネイルでページを並べ替えたりする
3. 「保存」（Ctrl+S）で、開いたPDFに上書き保存。別のファイルにするときは「名前を付けて保存」（Ctrl+Shift+S）

初回は準備に10秒ほどかかります（2回目からは速くなります）。

**PDFはどこにも送信されません。** 処理はすべて自分のPCのブラウザの中で行います。

## できること

| 分類 | 機能 |
|---|---|
| ページ番号 | **通しページ番号を一括で付与**（表紙を飛ばす、範囲ごとに書式・開始番号を変える、P.1 / - 1 - / 1/10 / ローマ数字など）、ヘッダー/フッター（工事名・日付・ファイル名）。画面にすぐ表示 |
| 文字 | 文字追加（ゴシック／太字／明朝／等幅、サイズ・色）、**PDFにもとからある文字の書き換え**（文字修正ツール）、**文字検索（Ctrl+F）**、**文字コピー**（囲んだ範囲の文字をコピー） |
| 文字認識 | **OCR**：スキャンや DocuWorks から変換した画像だけのPDFの文字を読み取り、検索・コピーできるようにする。保存したPDFは Acrobat などでも検索できる（表の数値に強い読み取り方） |
| 計測 | **距離**（水平・垂直に吸着）・**面積**（多角形）。縮尺 1/100 などを指定、または寸法がわかる線で縮尺を合わせる |
| 比較 | **2つのPDFの違いを色分け**（新だけ=赤、古だけ=青）。図面の改訂前後の確認に。違いのあるページを自動で探す |
| 書き込み | 白塗り（修正テープ）、**墨消し**（下の文字データごと削除）、マーカー、四角、楕円、線、矢印、手書き |
| DocuWorks風 | **付箋**、**日付印**（部署・日付・名前の丸印。前回の内容を記憶）、スタンプ（承認・確認済 など）、画像・印鑑画像 |
| ページ | 追加（PDF・画像・空白ページ）、ドラッグで並べ替え、削除、回転、複製、**差し替え**、**しおり（目次）**、複数PDFの結合 |
| 保存・印刷 | **上書き保存**、**注釈として保存**（Acrobat・PDF-XChange でも後から移動・修正・削除できる。他のソフトで付けた注釈もこのソフトで編集できる）、透かし文字、パスワード、圧縮、**用紙サイズをそろえる（A3→A4縮小など）**、選択ページのみ保存、印刷 |
| 大きなPDF | 1.4GB・2,300ページの計算書も開いて、ページ番号を付けて保存できる（約25秒） |
| 分割 | 選択ページの抽出、1ページずつ・Nページごと・範囲指定（例 `1-3, 4-6`）で分割 |
| 変換 | **DocuWorks（.xdw/.xbd）をドロップするとPDFにして開く**（数千ページの計算書も数分）、**PDF→画像（PNG/JPEG、解像度指定）**、**PDF→テキスト**、画像・SVG・XPS・テキスト→PDF、複数画像→1つのPDF |

元に戻す（Ctrl+Z）・やり直し（Ctrl+Y）、Ctrl+ホイールで拡大縮小、スペース＋ドラッグ（またはホイールボタン）で移動、
PageUp/PageDown/Home/End でページ移動、下の欄にページ番号を入れて移動。

## 注意

- 文字修正はPDFに文字データがある場合のみ。スキャンPDFは「白塗り」＋「文字追加」で対応してください。
- 文字認識（OCR）は完全ではありません。数値の確認には元の画像を見てください。1ページ数秒かかります。
- 「注釈として保存」した文字は、表示するソフトのフォントで表示されます（見た目を完全に揃えたいときは「固定する」）。
- 白塗りは見た目を隠すだけで、下の文字データは残ります（コピーや検索で拾えます）。
  文字そのものを消したい場合は「墨消し」を使ってください。
- Helvetica／Times は英数字専用です（日本語は表示されません）。
- パスワード付きのPDFは開けません。
- Word・Excel のファイルはブラウザでは直接読めません。各ソフトで PDF にしてから開いてください。
- DocuWorks（.xdw / .xbd）は、PCごとに1回だけ準備（画面の「変換」→「DocuWorks → PDF」→「初めて使うとき」から ZIP をダウンロードし setup.bat）すると、
  この画面にドロップするだけで PDF にして開けます。変換はそのPCの DocuWorks で行い、ファイルは外に送りません。ページは画像になります（文字の検索は不可）。

## DocuWorks → PDF の仕組み（`docuworks/`）

- `dw2pdf.ps1`：変換本体（PowerShell＋C#、Python 不要）。DocuWorks の `xdwapi.dll` でページを画像にし、PDF を直接書き出す。
  - 「自動」では、ページを 300dpi の白黒（G4 圧縮、1ページ数十KB）にし、色や灰色の塗りがある部分だけ 150dpi のカラー画像を透明マスク付きで重ねる。
    ほぼ全面カラーのページはカラー JPEG（既定 200dpi）。白黒／グレー／すべてカラーも選べる。
  - ページは CPU 数に合わせて同時に変換（最大 12）。日吉津グランルーフ計算書 v3（1,995 頁）で 1 頁あたり約 0.17 秒。
  - `-Serve`：PDF編集ソフトから呼ぶ変換ヘルパー。`127.0.0.1:52871` だけで待ち受け、受け付けるのは tkh-code.github.io と localhost の画面のみ。
    `/ping` `/convert`（POST でファイル本体）`/status` `/result` `/cancel`。
  - ファイル・フォルダを引数に渡すと（ショートカットへのドロップ／送る）その場でまとめて変換。
- `setup.bat`：`%LOCALAPPDATA%\DocuWorksPDF` に本体を置き、ログオン時の自動起動（スタートアップ）・`pdfeditor-dw://`（画面の「変換ツールを起動」ボタン用、HKCU）・デスクトップと「送る」のショートカットを作る。管理者権限は不要。
- `dw2pdf.zip`：配布用（`dw2pdf.ps1`・`setup.bat`・`README.txt`）。直したら作り直す（Compress-Archive）。ps1 は UTF-8（BOM 付き）で保存する。
- アンインストール：スタートアップ・デスクトップ・送る のショートカット、`%LOCALAPPDATA%\DocuWorksPDF`、レジストリ `HKCU\Software\Classes\pdfeditor-dw` を消す。
- 墨消しは保存したPDFで元に戻せません。元のファイルは残しておいてください。

## 仕組み・ライセンス

- PDF処理：[PyMuPDF](https://github.com/pymupdf/PyMuPDF)（AGPL）を [Pyodide](https://pyodide.org/) でブラウザ内実行
- フォント：BIZ UDPゴシック／BIZ UDP明朝／BIZ UDゴシック（Morisawa、SIL Open Font License、`fonts/OFL.txt`）
- ファイル構成：`index.html`（画面）、`worker.js`（処理の呼び出し）、`pdfcore.py`（PDF処理本体）
- ネットが使えないときの予備：`start.bat` でこのフォルダをPC内で配信して開けます（Python が必要。初回のエンジン取得にはネット接続が必要）
